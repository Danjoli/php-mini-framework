# Contribuindo

1. Abra ou selecione uma issue com escopo e critérios de aceite.
2. Crie uma branch `feat/`, `fix/`, `chore/`, `test/`, `docs/`, `refactor/` ou `security/`.
3. Use Conventional Commits.
4. Execute `composer check`.
5. Abra um Pull Request, aguarde a CI e solicite revisão.

Pull Requests devem ter foco único, testes para mudanças de comportamento e documentação quando alterarem a API pública. Não inclua credenciais, bancos locais ou dados pessoais.
